# Сумая, прости меня 🙈

Тёплая интерактивная открытка с извинениями, плавающими обезьянками, письмом с эффектом печатной машинки и банановым дождём. Это статический сайт: без сборки и сервера; достаточно открыть `index.html` или опубликовать файлы на GitHub Pages.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. После публикации сайт будет доступен по адресу `https://sardorras.github.io/love-cinematic-heart/`.

Все файлы сайта расположены в корне репозитория. Шрифты и конфетти загружаются с CDN; если CDN недоступен, сайт остаётся рабочим, а эффект конфетти просто пропускается.
