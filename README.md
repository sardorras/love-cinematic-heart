# 💕 LOVE - Cinematic Heart Animation

A beautiful, interactive cinematic animation website featuring a heart formed from hundreds of floating "LOVE" words.

## ✨ Features

- **Cinematic Animation**: Smooth, premium romantic experience
- **Canvas Optimization**: 400+ words rendered smoothly with WebGL-like performance
- **Heart Formation**: Words gradually form a perfect heart shape with smooth easing
- **Particle Effects**: Glowing particles and burst effects
- **Neon Glow**: Pink/red/white neon aesthetic
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **No Dependencies**: Pure HTML, CSS, and JavaScript
- **GitHub Pages Ready**: Deploy directly to GitHub Pages

## 🎬 Animation Sequence

1. **Floating Phase** (2s) - Hundreds of LOVE words float randomly across the screen
2. **Forming Phase** (3s) - Words gradually attract to the center and form a heart
3. **Pulsing Phase** (2.5s) - Heart pulses with neon glow effect
4. **Exploding Phase** (0.8s) - Words burst outward with particle effects
5. **Reforming Phase** (2s) - Words return to heart shape
6. **Repeat** - Animation cycles continuously

## 🚀 Deployment

### GitHub Pages
1. Go to repository Settings
2. Enable GitHub Pages from the `main` branch
3. Your site will be live at `https://sardorras.github.io/love-cinematic-heart/`

### Local Testing
Simply open `index.html` in your browser.
